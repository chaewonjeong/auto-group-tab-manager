# Icons Directory

This directory should contain the extension icons in the following sizes:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (Windows)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Requirements

- Format: PNG with transparency
- Design: Should represent tab organization/grouping
- Colors: Should work well in both light and dark themes
- Style: Follow Chrome extension design guidelines

## Temporary Solution

For development purposes, you can use any PNG files with the correct names and dimensions. The extension will load without icons, but they improve the user experience.

## Creating Icons

Recommended tools:

- Figma, Sketch, or Adobe Illustrator for vector design
- Export to PNG at the required sizes
- Optimize file sizes for faster loading
